# Rawstor benchmarks

This repository stores fio benchmark results for [librawstor](https://github.com/rawstor/librawstor). Each result includes the fio JSON and text output, along with metadata for the commit, branch, test configuration, and date.

Browse the [benchmark reports](docs/) or try the [interactive dashboard preview](https://izmdi.github.io/rawstor_bench/fio/librawstor/dashboard/).

## Dashboard

- **Overview** tracks IOPS and latency for a branch across selected test configurations. Filter by period and operation, and click a chart point to open its report.
- **Compare** supports up to eight branches. Choose a base branch and compare time series and percentage changes from the median of the latest N daily points per branch.
- **Together / Separate** switches between combined and separate Read and Write charts. Share the page URL to restore the current selection.

For each UTC day, branch, configuration, and metric (read/write IOPS or latency), the dashboard keeps the latest run that reported that metric. The Compare snapshot takes the median of the most recent `N` available daily points in each series.

## Build and preview locally

Use Python 3.10+ and Node.js 22+. CI runs Node.js 24.

```sh
npm ci
python3 tools/rawstor-bench-compile --prefix . fio
python3 tools/data-processor 0
npm run build
python3 -m http.server 8000 --directory docs
```

Open [the local dashboard](http://localhost:8000/fio/librawstor/dashboard/). Use `0` to include all available history. A positive number of days includes only dated runs in that window. An empty window yields empty charts. The HTML detail reports are generated by Jekyll for the published site.

## Import a benchmark result

```sh
python3 tools/rawstor-bench-import --prefix . --repo librawstor \
  --name <test-name> --branch <branch> --commit <sha> --date <iso-date> \
  fio <fio-output.txt> <fio-output.json>
```

Regenerate the reports and dashboard data with the commands above after importing results.

## Checks

- `npm test` runs the dashboard unit tests.
- `npm run test:python` tests imports, report generation, and data processing.
- `npm run test:browser` exercises the dashboard in headless Edge or Chromium. Set `BROWSER_PATH` if Edge is unavailable at the default Windows path. The tests serve the production bundle and local fixtures and can run offline after `npm ci`.
- `npm run typecheck` and `npm run build` verify the TypeScript and production bundle.

## Publishing

In the repository's **Settings → Pages**, select **GitHub Actions** as the source. The workflow builds reports and dashboard assets and deploys the site on pushes to `main`. It can also be run manually. Both triggers publish the full history. Pull requests run validation without deploying.
